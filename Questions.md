# 4 Метод оператора Лапласа, его достоинства и недостатки.

Идея: Использует вторые производные (лапласиан) для поиска "перегибов" функции яркости, которые соответствуют контурам.
Формула для непрерывного случая:
![alt text](img/image7.png)
![alt text](img/image8.png)

Достоинства:
- Изотропность: Не зависит от направления границы (одинаково реагирует на контуры любой ориентации).
Недостатки:
- Чувствительность к шуму: Как и все дифференциальные операторы, усиливает высокочастотный шум.
- Раздваивание границ: Если переход яркости не резкий, а пологий, лапласиан может дать два контура вместо одного.


# 5 Выделение контуров методом согласования.

Вместо того чтобы смотреть на отдельные пиксели, мы смотрим на целый участок (окно) и находим в нем общую закономерность.

![alt text](img/image11.png)
α - наклон по горизонтали (аналог производной по x)
β - наклон по вертикали (аналог производной по y)

Находим α и β

А затем вычисляес модуль градиента
$e_{(m,n)} = \sqrt{a^2 + β^2} $
![alt text](img/image10.png) 


Согласованный Лапласиан: В теории дает более помехоустойчивый оператор.

Критерий помехоустойчивости: Коэффициент усиления мощности белого шума Q. Он показывает, во сколько раз увеличивается дисперсия шума после обработки маской.

# 7 Как выбрать порог для получения изображения контуров?

Проблема выбора: Порог f0 определяет, какие перепады яркости считать контурами.
1. Анализ гистограммы: Строится гистограмма изображения e после выделения контуров.
Если на гистограмме есть два выраженных пика (один для фона, другой для контуров), порог выбирается между ними.
2. Экспериментальный подбор (визуальный контроль): Если гистограмма не имеет четких пиков, порог подбирается вручную, пока качество контурного изображения не станет удовлетворительным.

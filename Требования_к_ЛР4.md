тема: обнаружение объектов

# Цель работы:
изучение и экспериментальное исследование  методов обнаружения объектов на изображениях при помощи линейной обработки "окном", дальнейшее совершенствование навыков работы на автоматизированной системе обработки изображений в режиме диалога. 

Вариант 1. Для заданного преподавателем типа объекта исследовать корреляционный метод обнаружения при некоррелированном фоне. 
Числообъектов -  4. 
Определить число ложных и пропущенных объектов для дисперсии фона 3000 и 5000

Согласованный фильтр можно не делать
Достаточно сделать только коррелятор

Уточнение к л.р.4: 
постараться подобрать уровень шума таким образом,
чтобы обнаруживались не все объекты

Объекты: первый тип объектов в виде буквы Т размера 3х3
второй - такого же вида, но перевёрнутый

Исходных изображений три:
1) только фон. Объектов нет.
2) Есть объекты одного типа.
3) Есть объекты двух типов.

Для каждого из исходных изображений нужно показать:
- Исходное изображение фона - белого шума 
- Фон с добавленными объектами 
- Корреляционные поля (2 штуки для каждого исходного изображения) Результат пороговой обработки корреляционных полей

# Тема: выделение контуров

## Могут пригодиться функции

- scipy.signal.convolve2d
- numpy.sqrt

### Важно

1) Если в результате преобразования могут образоваться отрицательные значения, заранее преобразуйте массив к типу, допускающему отрицательные значения
2) Если на изображении есть отрицательные значения, прибавьте 128 при визуализации или используйте иной способ, не теряющий отрицательные значения при отображении
3) Если какое-то изображение плохо видно, контрастируйте его для наглядности.
4) объясните, как Вам удалось не потерять отрицательные значения изображений при вычислениях.

## **Задание:**

Реализовать алгоритмы выделения контуров на основе операторов градиента и лапласа, а также двумерной свёртки:

1) метод простого градиента
2) метод аппроксимации лапласиана (маски (20));
3) метод оператора Прюитт (маски (25));
4) метод согласования для лапласиана (маска (27));

## Требования

При отчёте на экране должны быть расположены следуюшие результаты (в нескольких или одном окне).

### Для градиентных методов

1) Исходное изображение
2) Частная производная по первому направлению
3) Частная производная по второму направлению
4) Оценка градиента
5) Гистограмма оценки градиента
6) Контуры "такой-то метод" (бинарное изображение)

### Для методов на основе второй производной

1) Исходное изображение
2) Оценка лапласиана
3) Гистограмма оценки лапласиана
4) Контуры "такой-то метод" (бинарное изображение)

### Нельзя использовать

1. циклы
2. стандартные функции:
    2.1 вычисления градиента и лапласиана
    2.2 выделения контуров
    2.3 пороговой обработки

### Можно использовать

- функцию двумерной свёртки или корреляции
- математические функции
- Размер изображения не обязательно 512х512. Можно другой.

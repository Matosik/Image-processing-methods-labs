# МЕТОД ДИФФЕРЕНЦИАЛЬНОГО КОДИРОВАНИЯ  ИЗОБРАЖЕНИЙ
Требования к оформлению Л.Р. №6 по МПАИ на ПИТОН
тема: дифференциальное кодировние

Термины
x(m,n) - исходное изображение
y(m,n) - уже обработанные отсчёты, совпадающие с отсчётами декомпрессированного изображения

Алгоритм сжатия.
----------------------
Развёртка построчная.

1) Предсказание p(m,n) = y(m,n-1)
2) Вычисление разностного сигнала f(m,n)=x(m,n)-p(m,n)
3) Квантование разностного сигнала равномерной шкалой
q=sign(f)*[(|f|+e)/(2e+1)]

e-задаваемая максимальная погрешность
[] - целая часть числа
|| - модуль числа
sign(f) - знак числа:
sign(f)= 1 if x>0 
sign(f)= 0 if x=0 
sign(f)=-1 if x<0 

4) Восстановление
y(m,n) = p(m,n) + q(m,n)*(2e+1)
значение y(m,n) используется для предсказания 
следующего элемента на шаге (1),
т.е. для вычисления p(m,n+1)

5) Массив q дожимается стат.кодером и кладётся в архив - (этот этап реализовывать не надо)

Алгоритм декомпрессии.
------------------------
догадаться самостоятельно

Задание
-------------------
1. Реализовать функцию q=MyDifCode(x,e,r)
входные параметры:
- x - изображение
- e - максимальная погрешность
- r - номер предсказателя выходные параметры
- q - массив квантованных разностей

2. Реализовать функцию y=MyDifDeCode(q,e,r)
входные параметры
q - массив квантованных разностей
e - максимальная погрешность
r - номер предсказателя выходные параметры
y - декомпрессированное изображение

3. С помощью этих функций построить график зависимости энтропии массива q (это оценка объёма сжатых данных) от максимальной погрешности e=0..50

4. На том же графике отбразить ту же зависимость для другого предсказателя (r=2): 
- p(m,n) = (y(m,n-1)+y(m-1,n))/2

5. Показать примеры декомпрессированных изображений для e=5, e=10, e=20, e=40
6. Показать разностный сигнал (изображение) при e=0 (контрастировать, чтобы было видно его)
7. Показать квантованный разностный сигнал (изображение) для e=0 e=5 и e=10 (контрастировать, чтобы было видно его)
8. Подтвердить, что выполняется контроль макс.ошибки

max(x(m,n)-y(m,n))<=e

Ещё раз: делаем только имитацию сжатия, то есть вычисляем только восстановленные картинки, массив квантованных значений и оценку объёма сжатых данных (энтропию).
